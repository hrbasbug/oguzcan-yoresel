# Oğuzcan Yöresel — Kurumsal Web Sitesi

Gaziantep'in doğal, katkısız ve el emeği yöresel lezzetlerini tanıtan çok sayfalı tanıtım ve sipariş sitesi.

## 🌐 Canlı Site

**https://oguzcan-yoresel.vercel.app**

## Sayfalar

- **Anasayfa** — Tanıtım hero'su, öne çıkan ürünler ve yaşam tarzı galerisi
- **Hakkımızda** — Hikâye, Vizyonumuz, Misyonumuz ve Değerlerimiz
- **Ürünlerimiz** — Kategori filtreli 31 ürün (Salçalar, Soslar, Baharatlar, Sirkeler)
- **İletişim** — WhatsApp, Instagram, konum ve Google Haritalar

## Özellikler

- Tamamen responsive tasarım (mobil + tablet + masaüstü)
- Her ürün için WhatsApp üzerinden tek tıkla sipariş bağlantısı
- Instagram ve WhatsApp butonları + sabit WhatsApp balonu
- Ürün kategorisi filtreleme
- Kaydırmada içerik animasyonları
- Kurulum/derleme gerektirmeyen saf HTML + CSS + JavaScript

## Yerelde Çalıştırma

Statik bir sitedir, derleme gerekmez. `site/` klasörünü herhangi bir statik sunucuyla açabilirsiniz:

```bash
npx serve site
```

Ardından tarayıcıda `http://localhost:3000` adresini açın.

## Teknoloji

Saf HTML5, CSS3 (Grid/Flexbox) ve vanilla JavaScript. Barındırma: Vercel.
